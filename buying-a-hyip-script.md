# Buying a HYIP script

Before you pay anyone, get these seven answers in writing. Telegram messages are fine.
Most disputes I have seen came from one of these being assumed instead of asked.

## 1. Do you get the files

Some vendors sell you a licence to a hosted install. You are renting. The day you argue
with them, your platform is gone. Ask straight out whether the code sits on your server,
under your domain, in your hosting account. If the answer is vague, it is a rental.

## 2. Whose name is the domain in

Your name. Not theirs, not their agency. Same for the server and the SSL. This sounds
obvious until you are three months in and need to move host, and the registrar account
belongs to somebody who has stopped replying.

## 3. What does the admin panel actually do

Not "full admin dashboard included". Specific things. Can you credit a balance. Can you
reject a withdrawal and give a reason. Can you edit a plan after launch. See the
[admin panel notes](admin-panel-controls.md) for the list I use.

## 4. Is the install done for you

Installation is where cheap scripts stop being cheap. If you have to hire someone to get
it running, add that to the price. A normal answer is that it is installed, configured and
handed over working, usually the same day.

## 5. What happens when it breaks

Ask for the support window in days and ask what counts as support. Bug in the script is
one thing. You asking for a new feature is another. Both are fine. Just know which is
which before you pay.

## 6. Can you see it before you buy

You should be able to click through a real install, both sides, without giving an email
address first. [investmentscript.com](https://investmentscript.com/) shows the whole thing
publicly and will hand you admin credentials to a live platform if you ask on Telegram.

## 7. Is the price one payment or a subscription

One payment for the build is normal. Renewals should only extend support, never switch the
software off. Read [what a HYIP script costs](hyip-script-price.md) for the ranges.

## After you buy

Change every default password before you tell anyone the domain. That includes the admin
login, the database user and the mail account. Bots find new installs faster than your
first real visitor does.
