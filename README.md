# HYIP script buyer notes

Notes for people about to buy a HYIP script or crypto investment platform software. No
source code here, just the checklist side of the decision.

Read them as a site: **https://hyipscript.github.io/hyip-script/**

* [Buying a HYIP script](buying-a-hyip-script.md), the seven things to get in writing first
* [What a HYIP script costs](hyip-script-price.md), the three price bands and what is not included
* [Admin panel controls that matter](admin-panel-controls.md), the checklist to compare listings against
* [Hosting and launch](hosting-and-launch.md), server, cron, backups, launch order
* [Crypto investment platform script](crypto-investment-platform-script.md), what the crypto part changes
* [Ready made or custom built](ready-made-or-custom.md), which one to start with
* [Nulled and rewrapped scripts](nulled-and-rewrapped-scripts.md), how to spot both

The platform these notes come from is [investmentscript.com](https://investmentscript.com/).
Both the investor front end and the [admin panel](https://investmentscript.com/features/admin-panel/)
are on the site screen by screen, and there is a [blog](https://investmentscript.com/blog/)
with longer versions of most of the topics above.
